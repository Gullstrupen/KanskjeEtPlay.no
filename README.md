# Kanskje et play?

Homepage for kanskjeetplay.no. Vite + React + TypeScript.

```bash
npm install      # first time only
npm run dev      # local preview at http://localhost:5173
npm run build    # type-check and build to dist/
npm run preview  # serve the built site at http://localhost:4173
```

- Edit the featured plays in `src/content/plays.ts`.
- Add the hero video in `public/media/` and point `heroVideo` in `src/content/site.ts` at it.

See `CLAUDE.md` for design principles and project rules.
